## 秘秘是什么？

秘秘（Mimi）是一个正在建设的个人 Agent 项目。我希望它能接住日常生活和工作里的真实任务：继续做上次没做完的事，使用你已经在用的工具，在需要时分工协作，也知道哪些决定必须由你来作。

**Mimi Harness** 负责把模型、工具与任务执行组织起来；**[MGRS](https://github.com/mor765504-gif/MGRS)** 则把授权、记忆、任务交接与行动边界这些值得公开讨论的原则整理出来。想更具体地了解为什么要做秘秘，可以读 [秘秘的产品想法](https://github.com/mor765504-gif/MGRS/blob/main/docs/MIMI-OVERVIEW.md)。

## 一起参与

不必先成为组织成员。可以从一个问题、一段经验或一个小原型开始。

- **产品与体验**：怎样让 Agent 在聊天、日程、研究和日常操作中真正省事？
- **工程与可靠性**：任务执行、外部工具、记忆、授权、交接、失败恢复和验证怎么做好？
- **治理与研究**：哪些行为可以由 Agent 自己决定，哪些必须留给用户？欢迎直接参与 [MGRS 的讨论](https://github.com/mor765504-gif/MGRS/issues)。

有兴趣一起做秘秘，可以在这里留下一个简短的协作意向：

**[→ 发起协作 / Start a collaboration](https://github.com/Mimi-personal-agent/join/issues/new?template=collaborate.yml)**

说说你关心什么、想解决什么问题就好，不需要正式简历。GitHub Issue 是公开的，请不要提交个人联系方式、密钥或私人数据。后续协作方式和代码访问按具体项目沟通。

## English

**Mimi** is a personal agent project built around everyday tasks, existing tools, longer-running work, and user control. The aim is to make an agent genuinely useful without asking people to surrender decisions they want to keep.

This repository is the **public starting point for collaboration**, not an automated organization invitation or a running join service. You can participate without organization membership.

- **Product & design:** Make agents practical in real workflows.
- **Engineering & reliability:** Work on integrations, task execution, memory, permissions, and verifiable outcomes.
- **Governance & research:** Discuss how agents should act, hand off work, and respect decisions in the public [MGRS project](https://github.com/mor765504-gif/MGRS).

**[→ Share a collaboration idea](https://github.com/Mimi-personal-agent/join/issues/new?template=collaborate.yml)**

A concrete problem or contribution idea is enough. Please avoid sensitive information in public issues. Access to private code and organization membership are considered separately when relevant.
